# Сортировка массива методом «Пузырька» (C++)

Программа создает массив размером 10 элементов, позволяет заполнить его вручную или случайными числами (от 1 до 100), а затем сортирует его по возрастанию. В конце выводится количество затраченных итераций.

## Описание алгоритма сортировки

В программе используется алгоритм **«Сортировка пузырьком»** (Bubble Sort).

**Как это работает:**
1. Программа проходит по массиву от начала до конца.
2. Она сравнивает каждую пару соседних элементов (например, `arr[0]` и `arr[1]`).
3. Если левый элемент больше правого, они меняются местами. Таким образом, самый большой элемент «всплывает» как пузырек в конец массива за один полный проход.
4. Процесс повторяется до тех пор, пока весь массив не будет отсортирован.

**Итерации:**
Итерацией в данной программе считается каждое сравнение двух соседних элементов. Программа подсчитывает общее количество таких сравнений и выводит результат на экран.
